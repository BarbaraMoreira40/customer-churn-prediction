# Customer Churn Prediction 🚀

This project uses Machine Learning to identify customers who are likely to cancel their subscription (Churn).

### 🛠 Technologies used:
* **Python** (Logic and data processing)
* **Pandas** (Data manipulation)
* **Scikit-Learn** (Machine Learning model)
* **Random Forest** (Algorithm)

### 📈 Goal:
Analyze contract time and monthly spend to predict if a customer will stay or leave, helping the business to take preventive actions.
